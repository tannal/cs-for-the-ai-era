# AI 时代的现代计算机科学课（第零课 ~ 第十课）

> **初期一切以硬核内容为核心。**
> 从计算机系统的第一性原理（`Abstraction / Interface / Specification vs Implementation`）出发，穿透编译、语言、平台、网络、存储、并行硬件与 7 大工程工种，最后落回工程师的工具效率、职场生存与工业社会反思。

---

## 课程总纲

### 第一部分：计算机系统的底层心智模型（第零课 ~ 第三课）
- **第零课：对计算机系统有一个基本认识**
  - 计算、编码、软件与硬件
  - 核心主线：`Abstraction / Interface / Specification` vs `Implementation`
  - **为什么“内存”本身就是一种 Abstraction**
  - 编译器是什么
  - 动手环境搭建（Windows `Scoop` + `Zed Nightly`）与延伸参考（Harvard CS50）
- **第一课：指令、状态、编程**
  - C 语言与机器指令序列（从 `foo.c` 到汇编 `mov` / `addi`）
  - 经典参考：台湾交通大学曹效忠老师（嵌入式系统实验课 / 操作系统设计与实现）、犹他大学嵌入式系统设计与实现
- **第二课：OOP 和高级语言——目前编程最好的规范化**
  - 为什么说“函数式编程在大多数情况下是垃圾”？OOP 与 C++ 的工程价值
  - 解释器与 JIT 编译器；显式中间代码语言（Java / Python / JS / Julia / R）
  - 编译器生态与 ABI：GNU / LLVM / Microsoft；Rust Cranelift；System-V / Apple / GNU / Microsoft ABI
  - 现代构建系统与依赖管理全景：
    - C/C++: `m4` → `autoconf` → `Makefile` → `CMake` → `Meson` → `xmake`
    - Rust: `Cargo` ｜ Java/JVM: `Maven / Gradle` ｜ Python: `uv / pyproject` ｜ JS/TS: `webpack / vite / rolldown / oxc`
  - 经典参考：Cliff Click 博士论文与 `Simple`（Sea of Nodes IR，V8 TurboFan 同源）、斯坦福相关课程
- **第三课：常见的软件系统——真正看懂什么是“平台”**
  - 分层抽象链路：`SoC / PC / 外设 → 操作系统（驱动/内核 Implementation）→ Abstraction → 应用开发者 ↔ 用户`
  - 树与 OOP 的本质：用来表达层次关系
  - **文件**（1950 年代操作系统虚构的 Abstraction）→ 硬盘；数据库系统 → 文件 → 硬盘
  - 平台全景：桌面平台 / Web 平台 / 移动平台 / 机房与互联网络 / 数据中心与异构平台 / 超算
  - 经典参考：台湾交通大学 Jserv（黄敬群）老师《嵌入式系统设计与实现》

### 第四部分：人、工具、职场与时代（第八课 ~ 第十课）
- **第八课：工具使用、效率、文档与 AI 正确姿势**
  - 身体健康即生产力：打字、人体工学键盘、椅子、颈椎、办公桌、平视屏幕、多喝水、防用眼用脑疲劳
  - **AI 使用第一性原则**：**AI 是拿来问的，不是拿来答的**（答的效果有 Claude 3.5+ 水平就够用，关键是配合知识库与最新信息）
- **第九课：打工人打工魂**
  - 生活基本盘：租房、水电、吃喝、休闲娱乐、卫生与居家小妙招
  - **理性升职状态机**：先承担目标职级责任并做出成果 → 汇报请求升职 → 同意则升职；拒绝则回退至当前职级职责，准备跳槽或创业 → 循环至满足
- **第十课：工业社会及其未来**
  - 工业社会塑造的现代日常：稳定食物与住所、朋友圈、朝九晚五、一日三餐
  - 当科技演进速度远超人类环境适应速度时，我们该如何自处
